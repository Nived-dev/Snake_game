# 🐍 Snake Game — Python

A classic Snake Game built with Python's built-in `turtle` graphics module. Control the snake, eat food to grow longer, increase your score, and avoid colliding with the walls or your own tail.

## 🎮 Features

- **Keyboard Controls:** Move the snake using the arrow keys.
- **Food & Growth:** Eat food to increase your score and snake length.
- **Score Tracking:** Displays your current score on the screen.
- **Collision Detection:** Detects collisions with walls and the snake's own body.
- **Object-Oriented Design:** Uses separate classes to organise snake movement, food generation, and score management.

## 🛠️ Technologies Used

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)

## 📁 Project Structure

```text
Snake_game/
├── main.py
├── snake.py
├── food.py
└── scoreboard.py
```

- `main.py` — Sets up the game window and manages the game loop.
- `snake.py` — Handles snake movement, direction controls, and growth.
- `food.py` — Generates food at random positions.
- `scoreboard.py` — Displays the score and game-over message.

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer. The `turtle` module is included with standard Python installations that support Tkinter.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Nived-dev/Snake_game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Snake_game
   ```

3. Run the game:

   ```bash
   python3 main.py
   ```

   On some systems, you may need to use `python main.py` instead.

## 🕹️ How to Play

| Key | Action |
|---|---|
| ↑ Up Arrow | Move up |
| ↓ Down Arrow | Move down |
| ← Left Arrow | Move left |
| → Right Arrow | Move right |

**Objective:** Eat as much food as possible, grow your snake, and avoid hitting the walls or your own body.
